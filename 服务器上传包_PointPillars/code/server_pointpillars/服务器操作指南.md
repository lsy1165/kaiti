# 服务器操作指南：PointPillars 检测展示版

本指南用于在 Linux GPU 服务器上完成单模态三维目标检测基础系统展示。

当前只做检测展示：

```text
多帧 demo 点云输入 -> PointPillars 预训练模型 -> 三维检测结果和 BEV 检测图
```

不训练模型，不要求完整 KITTI 数据。

## 一、需要上传到服务器的内容

上传这个文件夹即可：

```text
服务器上传包_PointPillars/
```

其中核心内容是：

```text
code/server_pointpillars/
code/data/stage02_mono3d_detection/demo_samples/
code/models/openpcdet/
```

上传包已经包含 demo 点云和预训练权重。

检测展示需要的两个文件是：

```text
code/data/stage02_mono3d_detection/demo_samples/*.bin
code/models/openpcdet/pointpillar_kitti.pth
```

其中 `demo_samples/` 当前包含基础点云 `000008.bin` 和 8 个 demo 变体，共 9 个 `.bin` 点云文件。变体只用于批量检测展示，不作为正式实验数据。

## 二、服务器建议条件

建议服务器具备：

1. Ubuntu 20.04 或 22.04；
2. NVIDIA GPU，显存建议 8 GB 以上；
3. CUDA 驱动可用，`nvidia-smi` 能正常显示；
4. Anaconda 或 Miniconda；
5. 不强制要求联网，因为上传包已包含 demo 点云和权重；联网只用于安装依赖和克隆 OpenPCDet。

## 三、上传示例

在本机 PowerShell 中可以使用：

```powershell
scp -r E:\kaiti\服务器上传包_PointPillars user@server_ip:/home/user/
```

然后进入服务器：

```bash
ssh user@server_ip
cd ~/服务器上传包_PointPillars
```

如果你用的是 AutoDL 的 root 容器，常见路径是：

```bash
cd /root/服务器上传包_PointPillars
```

如果终端提示符已经显示 `~/服务器上传包_PointPillars#`，说明已经在上传包根目录，不需要再执行 `cd`。

## 四、一键运行检测展示

赋予执行权限：

```bash
chmod +x code/server_pointpillars/*.sh
```

直接运行：

```bash
bash code/server_pointpillars/08_quick_demo_only.sh
```

该脚本会依次完成：

1. 检查服务器 GPU 和 conda；
2. 创建 `kaiti3d` conda 环境；
3. 安装 OpenPCDet；
4. 检查 PointPillars 预训练权重；
5. 检查 demo 点云，并生成多帧 demo 变体；
6. 跑 PointPillars 推理；
7. 保存检测结果。

## 五、分步运行方式

如果想一步一步执行：

```bash
bash code/server_pointpillars/00_check_server.sh
bash code/server_pointpillars/01_create_conda_env.sh
bash code/server_pointpillars/02_install_openpcdet.sh
bash code/server_pointpillars/03_prepare_demo_assets.sh
bash code/server_pointpillars/05_run_pointpillar_demo.sh
```

## 六、输出结果

检测展示输出目录：

```text
code/outputs/server_pointpillars_demo/
```

主要输出：

```text
predictions.json
000008_pred_bev.png
000008_backward_pred_bev.png
000008_forward_pred_bev.png
000008_forward_left_pred_bev.png
000008_forward_right_pred_bev.png
000008_near_left_pred_bev.png
000008_near_right_pred_bev.png
000008_shift_left_pred_bev.png
000008_shift_right_pred_bev.png
inference.log
```

其中：

1. `predictions.json` 保存三维检测框、类别和置信度；
2. `*_pred_bev.png` 是多帧点云 BEV 检测展示图；
3. `inference.log` 是推理日志。

## 七、可选完整 KITTI 流程

只有后续需要完整评估或训练时，才需要准备完整 KITTI 数据并运行：

```bash
bash code/server_pointpillars/03_link_kitti_data.sh
bash code/server_pointpillars/04_prepare_kitti_infos.sh
bash code/server_pointpillars/06_test_pointpillar_ckpt.sh
```

如果要训练，再运行：

```bash
bash code/server_pointpillars/07_train_pointpillar.sh
```

开题阶段优先完成检测展示，不强求训练。
