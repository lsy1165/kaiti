# 阶段 4 复杂工况增量上传包说明

这个文件夹只用于给已经跑通过 MVX-Net 的原服务器环境补充阶段 4 数据和脚本。

不需要重新安装环境，不需要重新跑 `01_install_mmdetection3d.sh`。

## 一、上传什么

把本文件夹里的：

```text
code/
```

上传到服务器已有目录：

```text
/root/服务器上传包_MVXNet/
```

上传后服务器上应该形成：

```text
/root/服务器上传包_MVXNet/code/data/stage04_complex_conditions/
/root/服务器上传包_MVXNet/code/server_mvxnet/04_run_complex_conditions.sh
```

如果提示覆盖，选择覆盖或合并。

## 二、当前已经准备好的数据

当前共有 6 组 clean/complex 对比数据：

```text
000008_low_light        # 弱光
000021_fog              # 雾天
000022_motion_blur      # 运动模糊
000023_image_noise      # 图像噪声
000024_lidar_sparse     # 点云稀疏
000025_lidar_jitter     # 点云扰动
```

每组目录结构都是：

```text
对比组ID/
  clean/      # 改变前原始图像、点云、pkl
  complex/    # 改变后复杂工况图像、点云、pkl
```

## 三、服务器上怎么跑

在服务器终端执行：

```bash
cd /root/服务器上传包_MVXNet
chmod +x code/server_mvxnet/*.sh
eval "$(conda shell.bash hook)"
export CONDA_ENV_NAME=base
conda activate base
bash code/server_mvxnet/04_run_complex_conditions.sh
```

这个脚本会对每组数据分别跑两次 MVX-Net：

```text
clean    # 改变前检测
complex  # 改变后检测
```

## 四、结果保存在哪里

服务器结果目录：

```text
/root/服务器上传包_MVXNet/code/outputs/stage04_complex_conditions/mvxnet_comparison_results/
```

结果结构：

```text
mvxnet_comparison_results/
  000008_low_light/
    clean/
    complex/
  000021_fog/
    clean/
    complex/
  ...
```

## 五、跑完后复制回本地哪里

把服务器这个目录：

```text
/root/服务器上传包_MVXNet/code/outputs/stage04_complex_conditions/mvxnet_comparison_results/
```

复制回本地：

```text
E:\kaiti\code\outputs\stage04_complex_conditions\mvxnet_comparison_results\
```

复制回来后，本地可以生成检测结果对比图：

```powershell
cd E:\kaiti
python code/src/stage04_complex_conditions/make_detection_comparison_previews.py
```

对比图会保存到：

```text
E:\kaiti\code\outputs\stage04_complex_conditions\detection_comparisons\
```
