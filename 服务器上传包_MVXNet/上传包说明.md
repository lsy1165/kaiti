# 服务器上传包说明：MVX-Net 多模态三维检测展示版

这个文件夹用于上传到 Linux GPU 服务器，复现图像+雷达多模态三维目标检测基础系统。

当前只做检测展示：

```text
相机图像 + 激光雷达点云 -> MVX-Net -> 多模态三维检测结果
```

不训练模型。基础多模态检测展示已经跑通后，可继续运行阶段 4 复杂工况批量检测脚本。

## 一、上传内容

当前上传包包含：

```text
code/server_mvxnet/
code/data/stage03_multimodal3d_detection/demo_samples/
code/models/mmdetection3d/
external/mmdetection3d/  # 如果已随包提供，则服务器不需要再 git clone
external/mmdetection3d_source.zip  # 如果上传这个压缩包，脚本会自动解压源码
```

其中 `demo_samples/` 已包含同一帧样例：

```text
000008.png
000008.bin
000008.pkl
```

## 二、服务器上从哪里开始

进入上传包根目录：

```bash
cd /root/服务器上传包_MVXNet
```

如果终端提示符已经显示在 `~/服务器上传包_MVXNet#`，说明已经在根目录，不需要再执行 `cd`。

## 三、按顺序执行

```bash
chmod +x code/server_mvxnet/*.sh
eval "$(conda shell.bash hook)"
export CONDA_ENV_NAME=base
conda activate base
```

然后分步运行：

```bash
bash code/server_mvxnet/00_check_server.sh
bash code/server_mvxnet/01_install_mmdetection3d.sh
bash code/server_mvxnet/02_prepare_demo_assets.sh
bash code/server_mvxnet/03_run_mvxnet_demo.sh
```

如果服务器卡在 `Receiving objects`，说明 GitHub 克隆太慢。可以按 `Ctrl + C` 停止，然后把本机的：

```text
E:\kaiti\服务器上传包_MVXNet\external\mmdetection3d_source.zip
E:\kaiti\服务器上传包_MVXNet\code\server_mvxnet\01_install_mmdetection3d.sh
```

上传覆盖到服务器对应位置，再重新执行：

```bash
bash code/server_mvxnet/01_install_mmdetection3d.sh
```

如果安装时出现：

```text
ModuleNotFoundError: No module named 'torch'
```

这是 `pip` 隔离构建导致临时环境找不到当前镜像里的 PyTorch，不是样例数据问题。请把本机最新版：

```text
E:\kaiti\服务器上传包_MVXNet\code\server_mvxnet\01_install_mmdetection3d.sh
```

上传覆盖服务器上的：

```text
/root/服务器上传包_MVXNet/code/server_mvxnet/01_install_mmdetection3d.sh
```

然后在服务器继续执行：

```bash
cd /root/服务器上传包_MVXNet
eval "$(conda shell.bash hook)"
export CONDA_ENV_NAME=base
conda activate base
bash code/server_mvxnet/01_install_mmdetection3d.sh
```

## 五、当前阶段说明

这一步用于证明图像+雷达多模态三维检测基础系统能够运行并输出结果。基础系统跑通后，可以继续进入复杂工况实验设计。

## 六、复杂工况批量检测

复杂工况阶段采用“多个原始样例，一一对应多种复杂工况”的方式，不采用同一帧生成多种工况的一对多方式。

当前复杂工况成组样例目录：

```text
code/data/stage04_complex_conditions/paired_samples/
```

该目录下每个对比组都包含 `clean/` 和 `complex/`，分别保存改变前和改变后的图像、点云和 pkl。准备好后，可以在服务器上传包根目录运行：

```bash
cd /root/服务器上传包_MVXNet
eval "$(conda shell.bash hook)"
export CONDA_ENV_NAME=base
conda activate base
bash code/server_mvxnet/04_run_complex_conditions.sh
```

复杂工况检测结果会保存到：

```text
code/outputs/stage04_complex_conditions/mvxnet_comparison_results/
```

结果目录按组保存：

```text
对比组ID/
  clean/
  complex/
```

如果要展示多种复杂工况，需要先向：

```text
code/data/stage04_complex_conditions/base_samples/
```

补充更多真实多模态样例三件套，然后重新运行：

```bash
python code/src/stage04_complex_conditions/create_one_to_one_conditions.py
```
