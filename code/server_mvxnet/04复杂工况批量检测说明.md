# 复杂工况批量检测说明

本脚本用于阶段 4：复杂工况下的 MVX-Net 多模态三维检测展示。

## 使用前提

先在本地或服务器上生成成组复杂工况样例：

```bash
python code/src/stage04_complex_conditions/create_one_to_one_conditions.py
```

样例目录应为：

```text
code/data/stage04_complex_conditions/paired_samples/
```

每个对比组必须包含：

```text
对比组ID/
  clean/
    原始样例.png
    原始样例.bin
    原始样例.pkl
  complex/
    复杂工况样例.png
    复杂工况样例.bin
    复杂工况样例.pkl
```

## 执行方式

在服务器上传包根目录运行：

```bash
cd /root/服务器上传包_MVXNet
eval "$(conda shell.bash hook)"
export CONDA_ENV_NAME=base
conda activate base
bash code/server_mvxnet/04_run_complex_conditions.sh
```

## 输出位置

```text
code/outputs/stage04_complex_conditions/mvxnet_comparison_results/
  对比组ID/
    clean/
    complex/
```

其中 `clean/` 是改变前检测结果，`complex/` 是改变后检测结果，避免不同工况和不同阶段结果混在一起。
