# 服务器操作指南：MVX-Net 多模态三维检测展示

本目录用于在 Linux GPU 服务器上复现图像+激光雷达多模态三维目标检测基础系统。

当前路线：

```text
KITTI 格式图像和点云样例 -> MMDetection3D -> MVX-Net -> 多模态三维检测结果
```

## 一、当前阶段目的

这一步对应导师意见中的：

```text
再复现图像+雷达的多模态三维目标检测基础系统，完成部署展示效果。
```

当前只做基础系统展示，不做复杂工况扰动。

## 二、上传内容

上传整个文件夹：

```text
服务器上传包_MVXNet/
```

其中核心内容是：

```text
code/server_mvxnet/
code/data/stage03_multimodal3d_detection/demo_samples/
code/models/mmdetection3d/
```

## 三、运行顺序

进入上传包根目录：

```bash
cd /root/服务器上传包_MVXNet
```

赋予脚本执行权限：

```bash
chmod +x code/server_mvxnet/*.sh
```

如果服务器镜像本身已经是 PyTorch 镜像，建议继续使用 `base` 环境：

```bash
eval "$(conda shell.bash hook)"
export CONDA_ENV_NAME=base
conda activate base
```

分步运行：

```bash
bash code/server_mvxnet/00_check_server.sh
bash code/server_mvxnet/01_install_mmdetection3d.sh
bash code/server_mvxnet/02_prepare_demo_assets.sh
bash code/server_mvxnet/03_run_mvxnet_demo.sh
```

## 四、输出结果

结果会保存到：

```text
code/outputs/stage03_mvxnet_demo/
```

跑完后把整个目录复制回本机：

```text
E:\kaiti\code\outputs\stage03_mvxnet_demo\
```

## 五、注意事项

1. 当前多模态样例只有 `000008` 一帧；
2. 这一步目标是跑通多模态基础系统，不做训练；
3. 如果安装环境出错，优先保存最后 30 行报错信息；
4. 复杂工况实验要等多模态基础系统跑通后再做。
