# 阶段 3：图像+雷达多模态三维检测路线说明

## 阶段目标

本阶段目标是复现一个图像+激光雷达融合的多模态三维目标检测基础系统，完成输入输出展示效果。

当前不做复杂工况扰动，也不做方法创新，先完成基础系统复现。

阶段 3 基础展示流程已经跑通，可作为后续复杂工况实验的基础。

## 推荐路线

当前优先路线：

```text
KITTI 格式图像和点云样例 -> MMDetection3D -> MVX-Net -> 多模态三维检测结果
```

选择 MVX-Net 的原因：

1. 它属于图像与点云融合的三维目标检测模型；
2. 与 KITTI 数据格式匹配度较高；
3. 工程复杂度低于 BEVFusion，适合作为多模态基础系统的第一步；
4. 能用于说明图像分支和点云分支共同参与三维检测。
