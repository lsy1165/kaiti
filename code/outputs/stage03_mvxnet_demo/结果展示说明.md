# MVX-Net 多模态三维检测结果说明

本目录保存阶段 3 图像+雷达多模态三维目标检测的服务器运行结果。

## 主要展示文件

```text
vis_camera/CAM2/000008.png
```

这是本阶段最适合展示的结果图。图中红色三维框为 MVX-Net 根据相机图像和激光雷达点云共同推理得到的三维目标检测结果，并根据相机与激光雷达标定关系投影到相机图像平面上进行展示。

这里的投影不是新的检测模型，也不是额外生成的原始数据，而是一种结果可视化方式：模型先输出三维空间中的检测框，再利用标定信息把三维框映射到图像上，便于观察检测框与道路场景目标是否对应。
