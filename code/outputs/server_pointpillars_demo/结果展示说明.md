# PointPillars 单模态三维检测结果展示说明

## 展示主题

单模态三维目标检测基础系统复现结果。

## 展示内容

本阶段以激光雷达点云作为输入，使用 PointPillars 预训练模型进行三维目标检测，并将检测结果以 BEV 鸟瞰图形式展示。

最清楚的一组对应展示是 `000008` 三件套：

```text
视觉图像：code/outputs/stage02_mono3d_detection/camera_images/000008_camera.png
原始点云：code/data/stage02_mono3d_detection/demo_samples/000008.bin
检测结果：code/outputs/server_pointpillars_demo/000008_pred_bev.png
```

详细对应关系见：

```text
code/outputs/stage02_mono3d_detection/000008三件套对应关系.md
```

可以重点展示以下文件：

```text
000008_pred_bev.png
000008_forward_pred_bev.png
000008_shift_left_pred_bev.png
predictions.json
inference.log
```

其中：

```text
*_pred_bev.png    # 点云 BEV 检测展示图
predictions.json  # 检测框、类别和置信度
inference.log     # 推理日志
```

## 图像说明

BEV 检测图中：

1. 散点表示激光雷达点云在鸟瞰图平面的分布；
2. 彩色矩形表示模型预测的三维目标框在 BEV 平面上的投影；
3. 文字标注表示目标类别和置信度；
4. 检测类别主要包括车辆、行人和骑行者。

点云没有相机照片那样的“原图”。如果需要展示原始点云输入，请使用单独目录：

```text
code/outputs/stage02_mono3d_detection/demo_input_bev/
```

本目录只保存 PointPillars 检测输出，不混放原始输入图。

这里使用 BEV 鸟瞰图是因为激光雷达点云本身是三维空间数据，不能像普通相机图像一样直接展示目标框。将点云和三维框投影到水平平面后，可以更清楚地观察车辆、行人等目标在道路平面上的位置关系。

## 可用于汇报的表述

当前已完成单模态三维目标检测基础系统复现。系统以 KITTI 格式激光雷达点云作为输入，使用 PointPillars 模型完成三维目标检测，并输出 BEV 视角检测结果图和结构化检测结果文件。该结果说明点云输入、模型推理、三维框输出和可视化展示流程已经跑通，可作为后续图像+雷达多模态三维目标检测复现的基础。

## 注意事项

当前 9 帧点云结果用于部署展示和流程验证，其中包含 demo 点云变体，不作为正式实验评测数据。后续正式实验仍需使用 KITTI、nuScenes 等公开数据集样本进行系统评估。
