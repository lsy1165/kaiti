# 视觉图像说明

本目录存放与 PointPillars demo 点云对应的相机图像。

当前真实对应关系：

```text
000008_camera.png  <->  code/outputs/server_pointpillars_demo/000008_pred_bev.png
```

说明：

1. `000008_camera.png` 是 `000008.bin` 对应的相机图像；
2. `000008_pred_bev.png` 是同一帧点云的 PointPillars 检测结果；
3. 其他 `000008_forward`、`000008_shift_left` 等结果来自点云展示变体，没有真实对应的相机图像。

展示时建议只使用 `000008_camera.png` 和 `000008_pred_bev.png` 做一组对应展示。
