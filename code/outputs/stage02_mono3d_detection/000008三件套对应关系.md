# 000008 展示三件套对应关系

展示单模态 PointPillars 三维目标检测效果时，优先使用下面这一组三个文件。

## 1. 视觉图像

```text
code/outputs/stage02_mono3d_detection/camera_images/000008_camera.png
```

作用：展示这一帧道路场景的相机视角，方便肉眼理解场景中大致有哪些车辆和道路目标。

## 2. 原始点云数据

```text
code/data/stage02_mono3d_detection/demo_samples/000008.bin
```

作用：这是 PointPillars 的实际输入数据。文件格式为 KITTI 点云 `.bin`，每个点包含 `x, y, z, intensity`。

如果需要展示原始点云的 BEV 可视化图，可以使用：

```text
code/outputs/stage02_mono3d_detection/demo_input_bev/000008_input_bev.png
```

## 3. 点云检测结果

```text
code/outputs/server_pointpillars_demo/000008_pred_bev.png
```

作用：这是 `000008.bin` 输入 PointPillars 后生成的检测结果图。图中散点表示点云，彩色矩形表示三维检测框在 BEV 平面上的投影，文字表示类别和置信度。

## 展示时的对应关系

```text
000008_camera.png      # 同一帧的相机视觉图像
000008.bin             # 同一帧的原始激光雷达点云输入
000008_pred_bev.png    # 同一帧点云经过 PointPillars 后的检测输出
```

## 注意事项

`000008_forward`、`000008_backward`、`000008_shift_left` 等文件是基于 `000008.bin` 生成的点云展示变体，用于验证批量推理流程，不是真实新场景，也没有对应的真实相机图像。

如果要向老师展示检测效果，优先展示 `000008` 这一组三件套，不要把其他变体和 `000008_camera.png` 混为同一帧。
