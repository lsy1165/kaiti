每个文件夹中的 `before.png` 为原始输入，`after.png` 为已有退化输入。每组使用不同的原始帧，未将同一帧扩展成六种工况。

上述操作在之前的数据准备阶段已经完成。本次没有重新制造退化数据，没有修改任何原始或退化的 `.bin`、`.png`、`.pkl` 输入文件。

## 本次如何生成图片

1. 从 `E:\kaiti\code\data\stage04_complex_conditions\paired_samples` 读取六组的 `pair_info.json`，确定每组 `clean` 和 `complex` 的文件对应关系。
2. 前四组直接复制该组已有的相机输入图片。没有从检测结果中抹除框，也没有重画场景。
3. 后两组直接读取对应 `.bin` 文件。每个点由4个float32数值组成：X、Y、Z、反射强度。
4. 读取该帧 `.pkl` 中已有的 `lidar2img` 标定矩阵，将XYZ坐标变成相机视角下的二维位置，再把有效视野内的点绘制到纯黑背景。这里的“相机视角”只是投影方向，没有叠加相机图像。
5. 前后采用同一矩阵、同一1242×375像素画幅、同一2×2像素点大小和同一距离色标。颜色表示点到雷达的距离，不表示检测置信度。没有单独调整某一张的颜色或显示比例，也没有放大扰动。

点云图中的黑色区域表示没有可显示的投影点。只显示相机视野内的点，因此画面中的点数少于完整点云文件的点数；不是额外删点。二维投影中不同点也可能落到同一像素。

## 已核对的内容

- 前四组：相机图像发生变化，点云数组保持完全相同。
- 后两组：相机图像的RGB像素完全相同，点云数组发生变化。PNG文件编码可能不同，因此使用像素而不是文件哈希判断图像内容是否变化。
- 稀疏组：退化后的全部XYZI点都能在原始文件中逐点找到，是原数据的严格子集。
- 扰动组：点数、点的对应顺序和反射强度不变，XYZ坐标差值的标准差约为0.08米。
- 每幅图片的来源文件、SHA256、投影参数和核对结果记录在本目录的 `source_manifest.json` 中。PPT图片的替代文字也记录了来源文件和哈希。

原始数据来自既有KITTI样例。退化数据是基于这些原始样例的程序模拟，不是现场采集的真实恶劣天气数据；投影图片是实际文件的可视化，不是AI生成图。
